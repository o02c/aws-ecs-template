# セキュリティ禁止事項一覧

> 出典: `docs/security_gide_template.md` 第2章より禁止事項のみを抽出
>
> 凡例:
> - **[SCP]** = SCP/Config/IAM Access Analyzer/Firewall Manager によるシステム的統制
> - **[手動]** = システム部門ユーザの目視確認・ガイドラインによる統制

---

## 2.1. 共通的な禁止事項

### [SCP] システム的統制

1. 個別許可されたAWSアカウントを除き、全ての他AWSアカウントのリソースに対するAPIアクションを禁止
2. 日本リージョン以外でAWSリソースを作成することの禁止
3. MS1ネットワーク内IP、および個別許可IP以外からのAWSリソースへのアクセスの禁止
4. 一部サービス（S3, KMS, Backup, GuardDuty, SecurityHub, IAM Access Analyzer, SNS）を除き大阪リージョンにおける操作を禁止
5. AWSアカウント内で保管している業務データを外部からAPIアクセス可能な設定にすることを禁止

### [手動] 手動運用統制

6. 全社/部門システム担当者が標準環境と同じ命名規則を利用してAWSリソースを作成することの禁止
7. AWSリソースに対し、標準環境と同じリソースタグを付与することの禁止
8. AWSアカウント内で保管している業務データを外部に持ち出すことの禁止
